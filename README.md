# COSMIX
Moon and Mars exploration game. `npm install`, then `npm run dev`. `npm run verify` runs the offline checks.
Controls: WASD move, Shift run, Space jump, mouse look, wheel zoom, E interact, hold F scan, R service nearest module, Tab colony panel, B build structures, M missions, Esc pause.
The outpost starts with a greenhouse, habitat, solar station, lab and storage/extraction unit; buildings you construct (B) appear in the world.
See DEVELOPMENT_STATUS.md for what works and what is untested.
Saves are per world and stay on this device. To start a colony over: main menu, Colony Management, Reset colony progress.
